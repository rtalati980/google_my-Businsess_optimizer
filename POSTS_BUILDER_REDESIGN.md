## 🎓 Usage Guide

### Creating a Campaign

1. **Select Template** (left sidebar)
   - Choose from 4 templates
   - Read description
   - See example content

2. **Add Details**
   - Type specific information
   - Reference example text
   - Optional: add image

3. **Generate Post**
   - Click "Generate with AI" button
   - Wait for content generation
   - Review in draft editor

4. **Edit & Refine**
   - Modify content
   - Watch character counter
   - Add/change image if needed

5. **Publish**
   - Click "Publish" button
   - Confirm with Google
   - See success message

6. **Track History**
   - View all campaigns below
   - See published vs drafts
   - Edit drafts as needed
