## 🎯 CALL TRACKING SETUP

### **Method 1: Google Ads Conversion Tracking** (Already Built!)
Your site already has conversion tracking. When someone:
1. Clicks your Google Business Profile
2. Calls your number OR visits your website
3. It's tracked in Google Ads dashboard

Use a service like:

- **Twilio** (logs all calls)
- **Google Call Extensions** (built-in Google Ads feature)

This tells you: "Which Google searches led to calls?"

### **Method 3: Simple Manual Tracking**
When someone calls, ask:
- "How did you hear about us?" → Track source
- "Which keyword did you search?" → Track keyword performance

## 🚨 COMMON MISTAKES TO AVOID

❌ **Don't:**
- Copy-paste generic description
- Use too many keywords (keyword stuffing)
- Make claims you can't back up
- Ignore the CTA
- Forget to add phone number
- Update only once (refresh quarterly!)

✅ **Do:**
- Use specific, detailed description
- Include 5-8 keywords naturally
- Be honest about services
- Have clear CTA
- Make phone number visible
- Keep description fresh
