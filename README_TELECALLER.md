## 🗺️ Google Maps Setup (5 Minutes)

### Get Free API Key

1. Go to: **console.cloud.google.com**
2. Create new project
3. Search and enable: **Places API**
4. Search and enable: **Maps JavaScript API**
5. Go to **Credentials** → **Create API Key**
6. Copy the key

### Use in Portal

1. Open `telecaller.html`
2. Click **🗺️ Google Maps (Real-Time)** tab
3. Paste API key
4. Enter location: "Mumbai, India" (or any city)
5. Select business type: Dental, Restaurant, Shop, etc.
6. Click **Fetch From Google Maps**

**That's it!** Real verified businesses load in seconds.

### Cost?

✅ **FREE** - 150 searches per month
- Most teams never exceed this
- Only pay if you scale massively ($0.03/search)
